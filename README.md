# HTML Tasks

This project contains HTML exercises and tasks.

## Topics Covered

- HTML Page Structure
- Headings and Paragraphs
- Images and Links
- Attributes
- Lists
- Tables
- Buttons
- Forms and Inputs
- Login Form
- Registration Form

## How to Run

1. Open the project in VS Code.
2. Open any HTML file.
3. Right-click on the file.
4. Select Open with Live Server.
